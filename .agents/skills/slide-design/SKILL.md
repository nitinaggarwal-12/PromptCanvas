# Slide Design & Native Editable Visual Architecture Workflow (`v2.0.0`)

## 1. Non-Negotiable Quality Pillars: Editable, Relevant, Complete, Grounded, Accurate & Cohesive
- **100% Native Editable (`0` Flattened Diagram Screenshots)**: Never paste flat, uneditable raster images of diagrams or text tables when depicting system boundaries, payload transformations, UML sequence lifelines, roadmaps, async state flows, or operating models. Every architectural visual MUST be constructed from native editable Google Slides / PptxGenJS vector shapes (`ROUND_RECTANGLE`, `RECTANGLE`, `ELLIPSE`, `RIGHT_ARROW`, `CAN`, `LINE` connectors, vector icons, and editable `TEXT_BOX` elements).
- **100% Relevant, Domain-Specific & Zero Copy-Pasted Example Text**: Visual archetypes define **visual structure and geometry**, NEVER static copy-pasted text. Never emit generic filler text (`Lorem ipsum`, `TBD`) or copy-paste example strings from reference screenshots (such as `"A2UI Portal"`, `"48-hour dormant review period"`, or `"Pub/Sub Topic"` into unrelated workstreams). Every component card, JSON key, actor name, sequence step, state transition, and roadmap phase must be synthesized directly from the active blog, workstream, or customer architecture.
- **100% Cohesive 12-Slide Pure Technical Narrative Flow (`Zero` Pricing Slides, `Zero` Dollar Pricing Figures, `Zero` Header/Headline Duplication & `Zero` Table Copy-Paste)**: Never include pricing slides (`quad-metrics` cost/pricing scorecards or `phased-roadmap-timeline` tier-pricing lifecycles) or dollar pricing figures (`$42/mo`, `$1,850/mo`, `$0.0042/turn`, etc.) unless explicitly requested by the user. A technical architecture slide deck must read as one unified, logical 12-slide story where each slide sets up the next (`Act I [Slides 1–3]: 3-Act Briefing Cover, Customer Use Cases & Google Cloud Stack, Architectural Options Matrix` $\rightarrow$ `Act II [Slides 4–7 — Top-Down Zoom L1->L2->L3->L4]: L1 3-Zone Logical Boundary, L2 Figure 1 #78 Physical Blueprint, L3 5-Actor Happy-Path UML Sequence & L4 Wire-Level Payload Triptych` $\rightarrow$ `Act III [Slides 8–12]: Fail-Closed Exception/OTel Feedback Loop, Automated Security/Breach/GAP-01..05 Verification Matrix, Live 16:9 Console Proof, 3-Pillar Well-Architected Solution Guarantees & 5-Workstream Series Deliverable Map`). Never duplicate Slide 5's 4-zone list on Slide 1; never repeat the top header bar breadcrumb verbatim as the main canvas headline (`Rule 25`); and never copy-paste table rows (`rawRows.slice(0, 4)`) into the bottom 4 synthesis cards of `comparison-grid` slides.
- **100% Complete**: Every visual archetype must include all required structural zones, step numbers (`1..6` or `1..5`), directional arrows, inline payload pills, actor icons, and `"Proprietary + Confidential"` footers without truncation (`0` `...` or `…` cutoffs).
- **100% Grounded in Live Systems, Authentic 16:9 Screenshots & Role-Neutral Enterprise Project Aliases**: Pair native editable diagrams with **authentic, single-environment live screenshots** (`real_gcp_*.png`, `real_ge_*.png`, `gcp_console_*.png`) inside `grounded-screenshot-proof` / `live-screenshot-callout` slides, accompanied by editable telemetry callout cards citing verified role-neutral GCP Project aliases/numbers (`ramp-portal-dev` `#248990048888`, `cymbal-pooled-prod` `#638420508320`, `cymbal-build-sandbox` `#887605034827` — `0` personal LDAP project strings in slide XML), Cloud Run revisions, BigQuery RLS policies, KMS HSM keys, and HTTP 200 log traces.
- **100% Accurate & Brand-Compliant (`Semantic 4-Zone Color Fidelity`)**: Enforce the sequential Google Quad-Color rule (`1. Blue #4285F4` → `2. Red #EA4335` → `3. Yellow #FBBC04` → `4. Green #34A853`) on generic 4-card layouts, while enforcing **Semantic Zone Color Fidelity** (`resolveSemanticZoneAccent`: `BLUE ZONE` = `#4285F4`, `GREEN ZONE` = `#34A853`, `YELLOW ZONE` = `#FBBC04`, `RED ZONE` = `#EA4335`) on Slide 5's 4-Zone Architecture Center (#78) sidebar so zone badges match the diagram canvas 1:1. Enforce `Google Sans` / `Google Sans Display` (`#3C4043`) + `Roboto` (`#5F6368`) + `Roboto Mono` / `Courier New` typography, `#F8F9FA` / `#DADCE0` (`8px` radius) neutral containers, `"Proprietary + Confidential"` on every slide footer, and Widescreen `16:9`.
