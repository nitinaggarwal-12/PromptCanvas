# PromptCanvas Canonical Visual Grammar Registry

**Status: FROZEN / CANONICAL companion registry**

This registry defines the 34 canonical visual grammars used to render views from the semantic architecture model. Visual grammars are not architecture families; they are reusable rendering/view types that can be applied to the canonical families at the appropriate architecture level.

## Usage rule

Select the **canonical architecture family first**, then its **L1/L2/L3 semantic depth**, then one or more visual grammars from this registry. Technology, cloud, industry, and assurance overlays bind to the semantic model; they do not create new visual grammar IDs.
